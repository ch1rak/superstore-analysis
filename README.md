# Superstore: анализ продаж и сегментация клиентов

Анализ заказов интернет-магазина с помощью pandas и SQL и сегментация клиентов (RFM + K-means).

Данные: [Superstore Dataset на Kaggle](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final). Файл `Sample - Superstore.csv` положи в папку проекта, в репозиторий он не входит.
